プライバシーポリシー

制定日：2026年11月3日

アプリ「ai-money-channel」（以下「本アプリ」）は、YouTube チャンネル「ミライ先生のAIマネー教室」の運営者が、自分のチャンネルに動画を予約投稿するためだけに使う個人用ツールです。

取得する情報

本アプリは、Google の OAuth 認証を通じて、運営者自身の YouTube チャンネルへの動画のアップロードとサムネイル設定の権限（YouTube Data API）を利用します。運営者以外の利用者の情報は取得しません。

利用目的

取得した権限は、運営者が承認した動画を運営者のチャンネルに予約投稿する目的にのみ使います。

第三者への提供

取得した情報を第三者に提供・販売することはありません。

Google API の利用について

本アプリによる Google API から受け取った情報の利用は、Limited Use の要件を含む Google API Services User Data Policy に従います。
